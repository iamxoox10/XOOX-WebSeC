# XOOX WebSeC

XOOX WebSeC is a lightweight web security auditing toolkit designed for
authorized testing and security assessment.

## Features

- Recon
- HTTP response inspection
- Security header audit
- TLS / SSL certificate inspection
- Port and service detection
- Basic SQL injection error-indicator detection
- Full security scan
- iSH / Alpine Linux friendly
